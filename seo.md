# PRD — SEO & Local SEO Enhancement

## Margasera Photography

**Website:** https://margasera.id/
**Project:** Margasera Photography
**Status:** Enhancement
**Prioritas:** High
**Target:** Meningkatkan visibilitas organik, brand recognition, local SEO, dan kepercayaan calon pelanggan.

---

# 1. Latar Belakang

Website Margasera Photography telah terdaftar di Google Search Console dan Google Analytics serta telah ter-index oleh Google.

Namun, ketika pengguna melakukan pencarian menggunakan keyword seperti:

* Margasera Photography Madura
* Margasera Pamekasan
* Margasera Madura
* Margasera Photo
* Margasera Foto

website belum mendapatkan posisi yang optimal dan Google terkadang menampilkan hasil dengan nama/entity yang mirip seperti "Magasari".

Masalah utama bukan lagi indexing, tetapi **Google belum memiliki sinyal yang cukup kuat untuk memahami hubungan antara:**

> Margasera Photography → Photography → Pamekasan → Madura

Project ini bertujuan memperkuat hubungan tersebut melalui technical SEO, on-page SEO, local SEO, structured data, content structure, dan social proof berupa testimonial pelanggan.

---

# 2. Tujuan

## Primary Goals

1. Memperkuat identitas **Margasera Photography** sebagai brand fotografi.
2. Memperkuat hubungan brand dengan **Pamekasan dan Madura**.
3. Meningkatkan ranking untuk branded keyword.
4. Meningkatkan peluang muncul pada pencarian lokal.
5. Membantu Google memahami entity/business Margasera.
6. Meningkatkan trust calon pelanggan melalui testimonial.
7. Mempertahankan karakter visual premium dan editorial website.

SEO tidak boleh dilakukan dengan keyword stuffing.

> Margasera Photography adalah fotografer profesional yang berbasis di Pamekasan, Madura, yang melayani wedding, pre-wedding, engagement, portrait, dan berbagai kebutuhan fotografi.

# 34. Catatan untuk Developer / AI Agent

**Jangan melakukan redesign besar.**

Pertahankan:

* visual identity
* typography
* animation
* cinematic feel
* existing navigation
* existing booking flow
* existing portfolio experience

Perubahan harus fokus pada:

**SEO + content structure + local SEO + entity signals + testimonial + conversion.**

Semua metadata harus dibuat **route-aware** jika menggunakan React Router.

Jangan menggunakan client-side metadata yang menyebabkan crawler mendapatkan metadata yang salah atau default untuk semua route.

Pastikan setiap route SEO memiliki:

```text
title
description
canonical
og:title
og:description
og:image
og:url
structured data
```

Jika memungkinkan gunakan SSR/SSG/prerendering sesuai arsitektur project agar metadata dan konten penting dapat dibaca crawler tanpa bergantung sepenuhnya pada JavaScript runtime.
