# Panduan File Suara Notifikasi Margasera

File suara notifikasi otomatis dibaca dari folder ini:
`public/sounds/notification.mp3`

### Rekomendasi Format Audio:
1. **Ekstensi & Format:** `.mp3` (MPEG Layer 3)
2. **Durasi:** 1 – 2 detik (nada pendek / chime / pop)
3. **Channel:** Mono (1 channel)
4. **Bitrate:** 64 kbps – 128 kbps
5. **Ukuran File:** Sangat ringan (< 30 KB), instan diputar oleh browser tanpa delay.

### Cara Pasang:
Cukup simpan/rename file suara Anda menjadi:
`notification.mp3` lalu taruh di dalam folder `public/sounds/` ini.
